# 架构决策索引

本节记录 `fqc` 项目的重要架构决策记录 (Architecture Decision Records, ADR)。

## 什么是 ADR？

架构决策记录是一种记录重要架构决策及其背景和后果的轻量级文档模式。每个 ADR 描述：

- **背景**: 决策的背景和问题陈述
- **决策**: 所做的决定及其理由
- **后果**: 决策带来的影响和权衡

## 决策流程

```mermaid
flowchart TD
    A[发现问题] --> B[分析选项]
    B --> C[评估权衡]
    C --> D[起草 ADR]
    D --> E{评审}
    E -->|需修改| F[更新草案]
    F --> E
    E -->|通过| G[采纳决策]
    G --> H[实施]
    H --> I[记录后果]
    
    style G fill:#90EE90
```

## ADR 模板

新的架构决策应遵循以下模板：

```markdown
# ADR-NNN: 决策标题

## 状态

[提议 | 评审中 | 已采纳 | 已废弃 | 已替代]

## 背景

描述决策的背景和问题。

## 决策

描述所做的决定及其理由。

## 替代方案

列出考虑过的其他选项。

## 后果

### 正面影响
- ...

### 负面影响
- ...

### 风险
- ...
```

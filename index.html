✦ 项目速览

产品fqc — 单一二进制 CLI（compress / decompress / info / verify）
格式族fqc-indexed/v2，与 C++ 实现的 fqc-sequential/v2 同名但 magic 不同、互不兼容，reader 以 magic 区分并明确拒绝异族
压缩策略组件分离（ID / 序列 / 质量 / aux 四流）+ 读长自适应编解码器（短读 ABC，中长读 Zstd）
访问模型尾部嵌入块索引 → O(log N) 随机访问、范围解压、按块验证；自包含，无附属索引文件
执行模式Archive（最佳压缩比）· Streaming（有界内存）· Pipeline（并发吞吐），三者产出同一格式
质量模式无损 Zstd（默认）/ SCM / illumina8 分箱 / qvz 量化 / discard
工程保证纯 Rust，unsafe_code = deny；格式契约测试 + 冻结归档 fixture 保护解码兼容
元数据Rust 1.75（MSRV）· MIT 之外采用 GPL-3.0-or-later

⚡ 常用命令

# 压缩（默认 Archive 模式，可加 --pipeline / --streaming）
fqc compress -i reads.fastq -o reads.fqc
fqc compress -i reads_R1.fastq -2 reads_R2.fastq -o paired.fqc

# 检视与校验
fqc info -i reads.fqc --detailed --show-codecs
fqc verify -i reads.fqc --quick

# 解压：全量、范围提取、恢复原始顺序
fqc decompress -i reads.fqc -o out.fastq
fqc decompress -i reads.fqc -o subset.fastq --range 1:1000
fqc decompress -i reads.fqc -o reads.fastq --original-order

# 有损质量（实验）：qvz / illumina8 / discard
fqc compress -i reads.fastq -o reads.fqc --lossy-quality qvz
